## 🎯 项目愿景

一个分层展开的互联网世界观知识库，从用户视角到大帝视角，一层一层揭示互联网背后的世界。

**核心特色：**
- 问题驱动，而非灌输
- 认知分层，从浅入深
- 从技术到社会，全景视野
