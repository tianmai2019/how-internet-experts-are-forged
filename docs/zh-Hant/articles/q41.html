🤖 第6層認知 · AI 時代視角

為什麼AI能說得很流暢，卻不一定總是正確？

流暢是一種模式匹配，不是一種事實核對

🤔 小白視角：這個問題為什麼重要？

你問 ChatGPT 一個問題，它答得又快又順，甚至還引用了參考文獻。你幾乎要在朋友圈轉發它了—— 直到你去查那本"參考文獻"，發現那本書根本不存在。

這就是所謂的"AI 幻覺"（hallucination）：

AI 一本正經地編造了看起來完全合理的內容。
它不是在騙你，它甚至"不知道"自己在騙你。

這個問題重要，是因為在信息爆炸的時代，"看起來專業"和"真的專業"之間的界限， 比過去任何時候都模糊。而 AI，讓這條界限更模糊了。

🧩 拆解：把大問題拆成小問題

  1. AI 是"怎麼說話"的？ 它的機制到底是什麼？
  2. 為什麼"流暢"這麼容易？ 而"正確"卻這麼難？
  3. 什麼是幻覺？ 為什麼模型會一本正經地胡說？
  4. 有辦法減輕幻覺嗎？ RAG、微調、事實核查有什麼用？

🎯 一層一層看

用戶層：只看結果

作為用戶，你看到的只有兩件事：它回答得又順又快，看起來像個專家。 你沒有理由不相信它——它講的每個字都很像那麼回事。

但流暢和正確，是兩個完全不同維度的事。流暢是關於"怎麼說"，正確是關於"說什麼"。 AI 極其擅長前者，在後者上卻經常翻車。

實現層：開始理解構造

在實現層，我們必須直面一個事實：大語言模型本質上是"下一個 token 的概率預測器"。

這裡的 token（詞元）是模型處理文字的最小單位——大約是"一個詞或半個詞"。 模型做的事很單純：給它一段文字，它輸出"下一個 token 最有可能是什麼"的概率分佈，然後按概率挑一個，接著重複。

Prompt: "珠穆朗瑪峰的高度是" 模型內部（簡化）： 下一個 token 的概率分佈： "8848" → 0.62 "8844" → 0.18 "8849" → 0.09 "一" → 0.05 "非常" → 0.03 ... 採樣 → 輸出："8848" 接著預測下一個 token → "米" 接著預測下一個 token → "。" ...

注意一件很關鍵的事：模型在挑 token 時，看的是"這個詞後面接什麼最像人類語料"， 而不是"這個數字是不是真的"。它沒有一個內置的"事實數據庫"去核對。

系統層：看到完整鏈路

把視野拉大。一個 LLM 回答問題，走的是這條鏈路：

你的問題（Prompt）
↓ 拆成 tokens
模型前向計算
↓ 輸出概率分佈
採樣下一個 token
↓ 拼回上下文，循環
流暢的回答文字

在這條鏈路裡，從頭到尾沒有一步是"去查證事實"。它只是在"接最合理的下一個詞"。 這種機制天然擅長兩件事：

  • 語法通順——因為它見過海量通順的句子。
  • 風格擬合——因為它見過學術、口語、法律、詩歌各種風格。

它天然不擅長的事只有一件：核對具體事實。 當訓練數據裡對某件事的說法有多種、模糊、甚至互相矛盾時，模型只會輸出"平均下來最像"的答案—— 這就是幻覺的溫床。

常見誤區："AI 是在檢索答案。"
不。它不是搜索引擎。它沒有在數據庫裡查東西。 它是在生成——每一個字都是當下"猜"出來的。 看起來像"引用"，其實是"合成"。

權衡層：為什麼這樣設計？

你會問：那為什麼不乾脆做一個"只說真話"的模型？答案是：沒人知道怎麼做。

當前的解決辦法都是"打補丁"，各有代價：

🔎 RAG（檢索增強生成）

先從真實文檔庫裡檢索片段，再讓模型基於片段回答。 優點：減少幻覺。代價：需要維護知識庫，檢索質量決定回答質量。

🎯 微調 / RLHF

用高質量數據讓模型學會"該說不知道就說不知道"。 優點：改善行為。代價：訓練貴，且模型仍會在訓練數據沒覆蓋的地方翻車。

🛠️ 工具調用（Tools / Agents）

讓模型學會"該查計算器就調計算器，該查數據庫就調 API"。 優點：把事實核對交給專門系統。代價：鏈路變長、延遲高、錯誤傳播。

👤 人類核查

最終由人來判斷答案對不對。 優點：可靠。代價：慢、貴，規模化困難。

所以，"流暢但不總是正確"不是 bug——是這一代模型架構的固有屬性。 你可以緩解它，但沒法從根源消除它。

✋ 動手試試

做一次"引用測試"

找一個你熟悉的領域，問 AI 一個偏具體的問題，比如：

"請引用 3 篇關於 XXX 的論文，附作者、年份和期刊。"

然後拿這 3 條去 Google Scholar 或期刊官網核對。 你大概率會發現：作者名字對不上、期刊張冠李戴、甚至整篇論文根本不存在—— 但 AI 的語氣絲毫沒變，像是在唸一份真實清單。

這個體驗會永久改變你對 AI 輸出的信任方式。

👑 大帝視角：這如何塑造現實？

流暢感，是新時代的說服力武器

在過去，"寫得漂亮"意味著"下過功夫"——它是能力的證明。 現在不是了。任何人、任何機器，都能瞬間生成一段"看起來極其專業"的文字。

這帶來兩個後果：

  • 信息可信度的錨點在漂移——過去我們信"寫得好"，現在得信"能核對"。
  • 閱讀者的責任變重了——你要學會在"看起來對"和"真的對"之間劃一條線。

第 6 層認知的關鍵不是"少用 AI"，而是對"流暢"這件事本身保持懷疑。 在 AI 時代，懷疑不是敵意，而是新的禮貌。

✨ 回到問題

為什麼 AI 能說得很流暢，卻不一定總是正確？

因為流暢來自模式匹配，正確來自事實核對——而當前的語言模型只做前者，不做後者。 它在計算"下一個詞應該是什麼"，不在計算"這句話是不是真的"。 流暢是它的天賦，正確是它需要外掛系統才能勉強得到的東西。

記住這一句就夠了：
當你面對 AI 的輸出時，問自己一件事——
"這句話，我能不能獨立核對？"
能核對的，用；不能核對的，謹慎。
