一個網頁到底是怎麼做出來的？

恭喜！你準備好成為創作者了

🤔 小白視角：這個問題為什麼重要？

你每天都在看網頁，但你有沒有想過：這些網頁是怎麼被創造出來的？

這個問題之所以重要，是因為它標誌著一個轉變： 從"使用者"到"創造者"。

第2層認知的覺醒：

原來網頁不是"長在網上"的，
而是有人一行一行寫出來的！

既然別人能寫出來，那我也能！

一旦你理解了這一點，整個互聯網在你眼裡就不一樣了。 你看到的不再是"現成的東西"，而是"我也能做的東西"。

🧩 拆解：把大問題拆成小問題

要做出一個網頁，你其實只需要理解三件事：

  1. 結構： 網頁上有什麼？（標題、圖片、按鈕...）
  2. 樣式： 它們長什麼樣？（顏色、大小、位置...）
  3. 行為： 它們會做什麼？（點擊有反應、數據變化...）

剛好，這三件事分別對應三種技術。

讓我們一個一個來看：

📄 HTML：內容骨架

HTML就像文章的大綱——告訴你這是標題、那是段落、那裡有張圖。

一個最簡單的HTML長這樣：

<!-- 這是註釋 -->
<html>
<head>
<title>我的第一個網頁</title>
</head>
<body>
<h1>Hello World!</h1>
<p>這是一個段落。</p>
</body>
</html>

看到了嗎？HTML用"標籤"來定義內容。 就像寫作時用"標題"、"段落"來組織內容一樣。

🎨 CSS：樣式和顏值

光有內容還不夠，我們需要讓它好看！CSS就是來做這個的。

假設我們有個標題，CSS可以決定：

h1 {
color: #10B981; /* 綠色 */
font-size: 32px; /* 字號 */
text-align: center; /* 居中 */
}

CSS的強大之處在於：它是描述性的。 你只需要說"我要這樣"，瀏覽器就會幫你做到。

⚡ JavaScript：讓網頁活起來

最後，我們需要交互。用戶點擊了要反應，輸入了要回應——這就是JavaScript的工作。
// 當按鈕被點擊時...
button.addEventListener('click', function() {
alert('你好！'); // 彈個窗
});

好！現在讓我們把三劍客合體，做一個真正的網頁！

✋ 現場演示：你的第一個網頁！

讓我們把HTML、CSS、JavaScript放在一起：

<!DOCTYPE html>
<html>
<head>
<style>
body { background: #F9FAFB; text-align: center; padding: 50px; }
button { background: #10B981; color: white; padding: 15px 30px; border: none; border-radius: 8px; font-size: 18px; cursor: pointer; }
</style>
</head>
<body>
<h1>🎉 我的第一個網頁！</h1>
<p>點擊下面的按鈕試試看~</p>
<button id="magic-btn">✨ 點我試試 ✨</button>
<p id="result"></p>
<script>
let count = 0;
document.getElementById('magic-btn').addEventListener('click', function() {
count++;
document.getElementById('result').innerText = `你已經點了 ${count} 次！`;
});
</script>
</body>
</html>

恭喜！你剛才看到的就是一個完整的現代網頁的全部代碼！

⚖️ 權衡層：為什麼這樣設計？

現在你可能會問：為什麼要分成三種語言？ 為什麼不把它們合併成一個？

關注點分離原則！

  • HTML：這東西是什麼？
  • CSS：這東西長什麼樣？
  • JS：這東西做什麼？

這樣分開後，修改其中一個不會影響另外兩個。

這就是軟件設計的智慧：把不同的東西分開來管。

✋ 動手試試

來！現在就做一個網頁！

1. 在電腦上新建一個文件，叫 index.html
2. 用記事本（或任何編輯器）打開它
3. 把剛才的代碼複製進去
4. 保存，雙擊打開！

你會看到你的第一個網頁在瀏覽器裡運行！

想玩得更嗨一點？試試修改代碼！

  • 把標題文字改成你的名字
  • 把按鈕顏色換成你喜歡的顏色（比如 #667eea）
  • 修改點擊後的提示文字

每次修改後刷新一下頁面——看！你在改變這個網頁！

從代碼到權力

一旦你理解了"網頁是寫出來的"，你就開始意識到：

所有你在網上看到的東西，都是某些人決定給你看到的。
而這些決定的背後，有價值觀、有商業、有政治、有偏見。

想想這些問題：

  • 為什麼這個按鈕這麼大？ 是為了讓你更容易點擊嗎？
  • 為什麼這個選項藏在這麼深的地方？ 是想讓你找不到嗎？
  • 為什麼這個顏色讓我感覺很緊迫？ 是故意設計的嗎？
  • 為什麼這個App讓我停不下來？ 是用了什麼心理學技巧嗎？

這就是從"只會用"到"看透"的轉變。 你看到的不再是"理所當然"，而是"有人這樣設計"。

✨ 回到問題

所以，一個網頁到底是怎麼做出來的？

答案是：
用HTML定義結構，用CSS定義樣式，用JavaScript定義行為， 然後用瀏覽器把它們變成屏幕上的畫面。
