為什麼平臺會越來越懂你喜歡看什麼？

你沒告訴它你喜歡什麼，但它就是知道

🤔 小白視角：這個問題為什麼重要？

打開抖音，前 5 個視頻還挺無聊；再刷 10 個，突然全是你感興趣的。用一週之後，你會發現它推的東西"精準得可怕"—— 你甚至沒搜過、沒點過贊，它就猜到了。

YouTube 會推給你下一個剛好想看的視頻，網易雲會做出一張讓你循環一整天的私人歌單， 淘寶在你還沒意識到自己想買什麼之前，就把它擺到了首頁。

這不是巧合，也不是"讀心術"。這背後是一整套推薦系統在你每次滑動、停留、跳過之間悄悄學習。

為什麼這個問題重要？
今天你看到什麼內容、買什麼東西、聽什麼歌、約會什麼人，越來越多是算法在替你篩選。 理解它的工作方式，就是理解為什麼"世界"呈現在你面前的樣子和別人不同。

🧩 拆解：把大問題拆成小問題

  1. 平臺怎麼知道你喜歡什麼？它從哪些行為裡讀出你的偏好？
  2. 為什麼它"越來越"懂？它是怎麼"學"的？
  3. 它推的是你真的喜歡的，還是你會點開的？這兩者其實不一樣。
  4. 為什麼兩個人打開同一個 App，看到的完全不同？

🎯 一層一層看

用戶層：只看結果

你只感受到兩件事：刷到喜歡的——愉悅；刷到不喜歡的——快速划走。

但你不知道的是：划走這個動作本身，就是最強的信號。你花在一個視頻上的每一毫秒，都在被記錄。 停留 3 秒 vs 停留 10 秒 vs 完播 vs 點贊 vs 轉發，每一個都是一票，一起決定"下一個推什麼"。

實現層：開始理解構造

最經典的思路叫協同過濾（Collaborative Filtering）：找到和你行為相似的人，看他們喜歡什麼，你大概率也喜歡。

🧍 你看過 A、B、C
↓ 找到"很像你"的人
🧍 他也看過 A、B、C，還看了 D
↓ 推理
🎯 那 D 也推給你

更現代的做法是把每個用戶和每個內容都變成一串數字（叫 embedding 向量）， 然後用"兩串數字有多接近"來衡量"你有多可能喜歡它"。

# 極簡偽代碼：一次推薦是怎麼算出來的 user_vec = embed_user(user_id) # [0.12, -0.34, 0.88, ...] 256 維 candidates = recall(user_vec, top=5000) # 從千萬條裡粗篩 5000 條 # 精排：為每一條打一個"你會喜歡的概率" scores = [] for item in candidates: item_vec = embed_item(item.id) p_click = model_ctr(user_vec, item_vec, context) # 會點嗎 p_finish = model_finish(user_vec, item_vec) # 會看完嗎 p_like = model_like(user_vec, item_vec) # 會點贊嗎 # 多目標融合：不同產品權重不同 score = 0.4 * p_click + 0.3 * p_finish + 0.3 * p_like scores.append((item, score)) feed = sorted(scores, key=lambda x: -x[1])[:20] # 你下拉刷出的 20 條

系統層：看到完整鏈路

從"你劃一下"到"推給你下一條"，其實是一個每秒運轉百萬次的巨大流水線：

📱 你的每一個動作
↓ 日誌上報
📊 行為日誌系統
↓ 特徵工程
🧠 模型訓練（離線 + 實時）
↓ 部署
🎯 推薦服務：召回 → 粗排 → 精排 → 重排
↓ 返回
📱 你的下一屏
整個鏈路裡有一個隱藏武器：A/B 測試。 平臺會同時跑幾十上百個"實驗版本"，隨機把 1% 的用戶扔進版本 A、另 1% 扔進版本 B， 看誰的完播率高、留存好，贏的那一版擴量。這才是"越來越懂你"的真正引擎——不是某個天才算法一次到位， 而是每天成千上萬次的小小勝出累積起來。

權衡層：為什麼這樣設計？

這裡藏著一個讓工程師和產品經理夜裡睡不著的問題："你喜歡的"和"你會點的"，其實是兩回事。

優化"點擊率"

短期指標飆升，你會一直刷。但內容越來越標題黨、情緒化、極端化——因為這些"最能騙你點一下"。

優化"長期滿意"

看似正確，但很難衡量：什麼算"滿意"？留存？回訪？還是"半年後你還會推薦給朋友嗎"？信號弱，訓練慢。

所以每一家平臺都在偷偷權衡：多讓你留一秒 vs 讓你幾年後還回來；給你新鮮感 vs 給你熟悉感； 推流量大的爆款 vs 推冷門優質。推薦系統的每一個參數背後，都是價值觀的選擇—— 只是這些選擇被藏在了工程師的表格和 A/B 實驗的勝率裡。

還有一個不得不面對的副作用：信息繭房。系統越懂你，就越傾向於給你"你會喜歡的"， 你就越少看到"你不會喜歡但可能重要的"。久而久之，你以為"世界就是這樣"，其實是"算法眼裡你以為的世界"。

✋ 動手試試

試試看：給自己開一個"小號"

註冊一個全新的抖音/YouTube 賬號，前 30 分鐘只看某一類內容（比如只看貓）。然後再隨便刷 10 分鐘， 觀察它給你推的內容佔比是怎麼變化的。

換個身份再試一次：這次只看某個完全不同的領域（比如烹飪）。 對比兩個小號看到的世界，你會親眼看到"算法眼中的你"是如何被塑造出來的。

想更工程一點，可以觀察這段 URL 參數：

GET /feed?user_id=xxx&last_seen=1690000000&session=abc &ab_bucket=exp_v3_variant_b ← 你被分到了 B 組 &refresh_reason=pull_down ← 你是下拉刷新的（不同來源，推的策略不同）

👑 大帝視角：這如何塑造現實？

從技術到世界

過去我們以為"品味是自己養出來的"——你聽什麼歌、愛哪個電影、支持哪個球隊，都是你自由選擇的結果。 現在越來越多的證據表明：你的品味有一半是被推薦系統塑造出來的。 它先猜你會喜歡什麼，你被推得多了，就真的開始喜歡，反過來又變成它下一次訓練的正樣本。

這是一種非常安靜的權力。它不告訴你不能看什麼，它只是不給你看某些東西； 它不告訴你必須相信什麼，它只是讓某些觀點每天出現三次，讓另一些永遠不出現。

更讓人不安的是：這些系統的目標函數（optimize target）是它的商業目標，不是你的人生目標。 它想讓你多刷 3 分鐘，而不是讓你更幸福、更博學、或者更有勇氣。 兩者有時候重疊，但常常不重疊。

所以理解推薦系統，本質上是理解一件事：你面前的信息流，不是"世界"，而是"世界的一份為你定製的版本"。 而定製它的人，不是你自己。

✨ 回到問題

為什麼平臺會越來越懂你喜歡看什麼？

答案是：因為你每一次滑動、停留、點贊、跳過，都被變成一個數字， 喂進一個每天都在自我更新的模型。它不是"懂你"，它是用你過去的行為預測你下一秒的行為， 然後把預測最準的那條推到你眼前。 久而久之，它塑造的不只是你的信息流，還有你的品味、你的情緒、你以為的自己。
