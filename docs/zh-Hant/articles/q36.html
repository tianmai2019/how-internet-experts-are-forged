為什麼互聯網產品設計，最後會影響人的情緒、表達和判斷？

當技術媒介重塑了情感的語法

🤔 小白視角：這個問題為什麼重要？

你有沒有過這些感覺？

  • 看完 15 分鐘短視頻，情緒莫名煩躁；
  • 刷完一晚上評論區，忍不住想跟人吵架；
  • 看到一個新聞標題，還沒讀完就已經憤怒；
  • 在朋友圈刷到"別人的生活"，突然焦慮起來。

這些情緒不是"你"，也不是"內容"，而是你和產品設計的共同產物。 同樣一件事，報紙上讀到、朋友嘴裡聽到、抖音上刷到、微博熱搜上看到—— 你的情緒反應完全不同。

產品設計，是情緒的"揚聲器"。

它決定了什麼情緒被放大、什麼情緒被壓制、
什麼樣的表達能傳播、什麼樣的觀點會消失。

🧩 拆解：把大問題拆成小問題

  1. 為什麼"憤怒"在互聯網上傳播最快？
  2. 為什麼評論區容易極端化？
  3. 為什麼"信息繭房"會重塑判斷？
  4. 為什麼表達變得越來越"表演化"？

🎯 一層一層看

用戶層：只看結果

普通用戶的感受："這個平臺戾氣好重。""網友怎麼這麼極端？""網上都是鍵盤俠。"

但你注意到沒——離開這個 App，那些"戾氣"就沒了。不是人變了，是環境變了。

實現層：開始理解構造

內容分發的核心邏輯，用一段簡化的偽代碼就能表達：

// 一條內容能不能被推薦？看它的"互動率" score = weight_1 * click_rate + weight_2 * complete_rate + weight_3 * comment_rate // 評論最貴！ + weight_4 * share_rate + weight_5 * follow_rate // 什麼內容最容易觸發評論和轉發？ // —— 情緒強烈的內容 // —— 立場鮮明的內容 // —— 令人憤怒/驚訝/焦慮的內容 // 於是算法自然會"選擇"這些內容， // 因為它們最能帶來"高價值互動"

算法本身沒有情緒傾向，但因為它優化"互動率"——而憤怒是最能引發互動的情緒—— 所以它系統性地放大了憤怒。這不是陰謀，是數學的自然結果。

系統層：看到完整鏈路

一個"情緒的正反饋循環"是這樣發生的：

憤怒的內容 → 高互動率 → 算法多推 ↓ 更多人看到 → 更多人評論 → 更多人轉發 ↓ 憤怒的評論區，進一步激發新的憤怒 ↓ 創作者發現"憤怒有流量" → 生產更多憤怒 ↓ 整個平臺的"情緒基線"被抬高

這就是 MIT 那篇著名論文說的："Falsehood diffuses faster than truth." （謠言比真相傳播得快，因為它更令人驚訝。）

權衡層：為什麼這樣設計？

你可能會問：為什麼不讓算法優化"溫和的、深思熟慮的內容"？ 答案是那樣做，平臺會失去流量，用戶會流失：

憤怒驅動的設計

用戶停留久、互動多、廣告收入高——但社會情緒被撕裂。

平靜驅動的設計

用戶理性、內容更好——但停留時間短、增長慢，商業上競爭不過對手。

在商業競爭的壓力下，幾乎所有平臺最終都被拉向前者。 這不是某個人的選擇，是整個行業的均衡。

✋ 動手試試

🔍 情緒日記實驗

做一次為期 3 天的觀察：

  1. 每次打開某個 App 前，記錄你的情緒（1-10 分）；
  2. 關閉後，再記錄一次；
  3. 看看：哪些 App 讓你情緒變好了？哪些讓你變差了？
  4. 額外一步：找一天完全不刷微博 / 抖音 / 朋友圈，看看你會想些什麼。

很多人做完這個實驗會震驚——某些 App 每次刷完，我都變得更煩躁，但我停不下來。 這就是"情緒工程"的具體體現。

👑 大帝視角：這如何塑造現實？

技術媒介重塑了情感的語法

Marshall McLuhan 說："The medium is the message."（媒介即訊息。） 這句話在 2020 年代變得極其精準：

  • Twitter/X 的 280 字符——培養了"金句思維"，鼓勵尖銳、簡化、極端；
  • 短視頻的 15 秒——獎勵強刺激開頭，讓深度表達無處生存；
  • 評論區的按序展示——讓"最激烈的評論"永遠排在最前；
  • 點贊數的可見——讓"表演性表達"勝過"真實表達"。

你在這些平臺上"發言"，其實是在參加一場特定規則的比賽。 比賽規則獎勵什麼，你就慢慢學會說什麼、感受什麼、相信什麼。

最深的影響不是"你今天生氣了"——而是你的情緒反應模式，被這些平臺重新校準了。 過去讓你憤怒需要一件大事，現在一個標題就夠；過去表達一個觀點要想半天，現在幾秒就能"輸出"； 過去我們說"我理解你"，現在我們說"我 diss 你"。

這是技術媒介重塑情感語法的力量——比任何廣告都深，比任何政治都久。

✨ 回到問題

所以，為什麼互聯網產品設計，最後會影響人的情緒、表達和判斷？

答案是：因為產品設計不只是"承載"信息，它決定了信息如何流動、什麼被放大、什麼被壓抑。 當幾十億人每天幾小時地生活在同一個"信息流動規則"裡， 這個規則最終會塑造他們感受世界的方式。

看到這一點，你就可以問自己一個真正重要的問題：

我最近的"感受"，有多少是真實世界給我的？
有多少，只是某個推薦算法給我的？
