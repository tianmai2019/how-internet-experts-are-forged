为什么互联网产品设计，最后会影响人的情绪、表达和判断？

当技术媒介重塑了情感的语法

🤔 小白视角：这个问题为什么重要？

你有没有过这些感觉？

  • 看完 15 分钟短视频，情绪莫名烦躁；
  • 刷完一晚上评论区，忍不住想跟人吵架；
  • 看到一个新闻标题，还没读完就已经愤怒；
  • 在朋友圈刷到"别人的生活"，突然焦虑起来。

这些情绪不是"你"，也不是"内容"，而是你和产品设计的共同产物。 同样一件事，报纸上读到、朋友嘴里听到、抖音上刷到、微博热搜上看到—— 你的情绪反应完全不同。

产品设计，是情绪的"扬声器"。

它决定了什么情绪被放大、什么情绪被压制、
什么样的表达能传播、什么样的观点会消失。

🧩 拆解：把大问题拆成小问题

  1. 为什么"愤怒"在互联网上传播最快？
  2. 为什么评论区容易极端化？
  3. 为什么"信息茧房"会重塑判断？
  4. 为什么表达变得越来越"表演化"？

🎯 一层一层看

用户层：只看结果

普通用户的感受："这个平台戾气好重。""网友怎么这么极端？""网上都是键盘侠。"

但你注意到没——离开这个 App，那些"戾气"就没了。不是人变了，是环境变了。

实现层：开始理解构造

内容分发的核心逻辑，用一段简化的伪代码就能表达：

// 一条内容能不能被推荐？看它的"互动率" score = weight_1 * click_rate + weight_2 * complete_rate + weight_3 * comment_rate // 评论最贵！ + weight_4 * share_rate + weight_5 * follow_rate // 什么内容最容易触发评论和转发？ // —— 情绪强烈的内容 // —— 立场鲜明的内容 // —— 令人愤怒/惊讶/焦虑的内容 // 于是算法自然会"选择"这些内容， // 因为它们最能带来"高价值互动"

算法本身没有情绪倾向，但因为它优化"互动率"——而愤怒是最能引发互动的情绪—— 所以它系统性地放大了愤怒。这不是阴谋，是数学的自然结果。

系统层：看到完整链路

一个"情绪的正反馈循环"是这样发生的：

愤怒的内容 → 高互动率 → 算法多推 ↓ 更多人看到 → 更多人评论 → 更多人转发 ↓ 愤怒的评论区，进一步激发新的愤怒 ↓ 创作者发现"愤怒有流量" → 生产更多愤怒 ↓ 整个平台的"情绪基线"被抬高

这就是 MIT 那篇著名论文说的："Falsehood diffuses faster than truth." （谣言比真相传播得快，因为它更令人惊讶。）

权衡层：为什么这样设计？

你可能会问：为什么不让算法优化"温和的、深思熟虑的内容"？ 答案是那样做，平台会失去流量，用户会流失：

愤怒驱动的设计

用户停留久、互动多、广告收入高——但社会情绪被撕裂。

平静驱动的设计

用户理性、内容更好——但停留时间短、增长慢，商业上竞争不过对手。

在商业竞争的压力下，几乎所有平台最终都被拉向前者。 这不是某个人的选择，是整个行业的均衡。

✋ 动手试试

🔍 情绪日记实验

做一次为期 3 天的观察：

  1. 每次打开某个 App 前，记录你的情绪（1-10 分）；
  2. 关闭后，再记录一次；
  3. 看看：哪些 App 让你情绪变好了？哪些让你变差了？
  4. 额外一步：找一天完全不刷微博 / 抖音 / 朋友圈，看看你会想些什么。

很多人做完这个实验会震惊——某些 App 每次刷完，我都变得更烦躁，但我停不下来。 这就是"情绪工程"的具体体现。

👑 大帝视角：这如何塑造现实？

技术媒介重塑了情感的语法

Marshall McLuhan 说："The medium is the message."（媒介即讯息。） 这句话在 2020 年代变得极其精准：

  • Twitter/X 的 280 字符——培养了"金句思维"，鼓励尖锐、简化、极端；
  • 短视频的 15 秒——奖励强刺激开头，让深度表达无处生存；
  • 评论区的按序展示——让"最激烈的评论"永远排在最前；
  • 点赞数的可见——让"表演性表达"胜过"真实表达"。

你在这些平台上"发言"，其实是在参加一场特定规则的比赛。 比赛规则奖励什么，你就慢慢学会说什么、感受什么、相信什么。

最深的影响不是"你今天生气了"——而是你的情绪反应模式，被这些平台重新校准了。 过去让你愤怒需要一件大事，现在一个标题就够；过去表达一个观点要想半天，现在几秒就能"输出"； 过去我们说"我理解你"，现在我们说"我 diss 你"。

这是技术媒介重塑情感语法的力量——比任何广告都深，比任何政治都久。

✨ 回到问题

所以，为什么互联网产品设计，最后会影响人的情绪、表达和判断？

答案是：因为产品设计不只是"承载"信息，它决定了信息如何流动、什么被放大、什么被压抑。 当几十亿人每天几小时地生活在同一个"信息流动规则"里， 这个规则最终会塑造他们感受世界的方式。

看到这一点，你就可以问自己一个真正重要的问题：

我最近的"感受"，有多少是真实世界给我的？
有多少，只是某个推荐算法给我的？
